Image Filtering & Convolution
The foundation of CV. A kernel (small matrix) slides over the image, computing a weighted sum at each pixel. This is discrete 2D convolution.
⊛
2D Convolution
core math
Output(x,y) = Σ Σ I(x+i, y+j) · K(i,j) i j cv2.filter2D(img, -1, kernel)
KERNEL (3×3)
Key insight: Larger kernels = more blur/effect but slower (O(n²) per pixel). Separable kernels split into 1D passes for speed.
∿
Gaussian Blur
low-pass filter
σ (sigma) 8
G(x,y) = 1/(2πσ²) · e^(-(x²+y²)/2σ²) cv2.GaussianBlur(img, (ksize,ksize), σ)
Separable: G(x,y) = G(x)·G(y), so it decomposes into two 1D passes — O(kn) instead of O(k²n). Used in Canny, SIFT, and scale-space.
◈
Bilateral Filter
edge-preserving
BF[I](p) = 1/Wₚ · Σ Gσs(||p-q||)·Gσr(|Ip-Iq|)·Iq q cv2.bilateralFilter(img, d, σColor, σSpace)
Two Gaussians: spatial (distance in pixels) and range (intensity difference). Only blurs pixels with similar color → edges preserved. Used for HDR tone-mapping, skin smoothing.
Edge Detection
Edges are locations of rapid intensity change — computed via image gradients. Different operators have different math and frequency responses.
∇
Sobel / Gradient
1st derivative
Gx (horizontal)
Gy (vertical)
G = √(Gx² + Gy²) θ = arctan(Gy/Gx) cv2.Sobel(img,cv2.CV_64F,1,0,ksize=3) # x cv2.Sobel(img,cv2.CV_64F,0,1,ksize=3) # y
Magnitude = edge strength. Angle θ = edge direction (perpendicular to gradient). Scharr is more rotationally symmetric. Laplacian uses 2nd derivative.
⚡
Canny Edge Detector
multi-stage pipeline
John Canny (1986): Optimal edge detector — maximizes SNR and localization. Hysteresis thresholding links edges using high/low thresholds to avoid breaks.
edges = cv2.Canny(img, threshold1=100, threshold2=200) # threshold1=low, threshold2=high for hysteresis
△
Laplacian / LoG
2nd derivative
∇²f = ∂²f/∂x² + ∂²f/∂y² Laplacian kernel: LoG combines Gaussian [ 0 1 0] blur (removes noise) [ 1 -4 1] then Laplacian. [ 0 1 0] Zero-crossings = edges
Sign changes (zero-crossings) mark edges. More sensitive to noise than Sobel — hence the Laplacian of Gaussian (LoG) pre-smooths first. Useful for blob detection.
Geometric & Frequency Transforms
Mapping images between coordinate spaces, and analyzing images in the frequency domain via the Fourier Transform.
⟲
Affine & Perspective
geometric
Affine: [x'] = [a b tx][x] [y'] [c d ty][y] [1] M = cv2.getRotationMatrix2D(center,angle,scale)
Affine = 6 DOF (translation, rotation, scale, shear) — preserves parallelism. Perspective = 8 DOF — maps any quadrilateral to another. Requires 3 or 4 point correspondences.
◎
Hough Transform
parameter space
Line: ρ = x·cos(θ) + y·sin(θ) Each edge pixel votes in (ρ,θ) accumulator. Peaks = lines. cv2.HoughLinesP(edges, rho=1, theta=π/180, threshold=100, minLen=50)
Accumulator array (Hough space): every edge pixel draws a sinusoid. Where sinusoids intersect = a real line in image space. Circle Hough is 3D: (cx, cy, r).
∿
Fourier Transform (DFT)
frequency domain
Freq filter 60%
F(u,v) = Σ Σ f(x,y)·e^(-j2π(ux/M+vy/N)) x y dft = cv2.dft(img.astype(np.float32), flags=cv2.DFT_COMPLEX_OUTPUT)
Low freq (center) = overall shape/brightness. High freq (edges) = fine details and noise. Masking in freq space = convolution in spatial space (convolution theorem).
Feature Detection & Description
Finding repeatable, distinctive points in images that can be matched across different views, scales, and lighting conditions.
◇
Harris Corner Detector
eigenvalue analysis
M = Σ w(x,y)[Ix² IxIy] R = det(M) - k·trace(M)² window [IxIy Iy²] R > 0 → corner |R| small → flat R < 0 → edge cv2.cornerHarris(gray, blockSize=2, ksize=3, k=0.04)
Structure tensor M captures local gradient distribution. Both eigenvalues large = corner. One large = edge. Both small = flat. k≈0.04–0.06 (Harris-Stephens empirical).
⬡
SIFT — Scale Invariant Feature
scale & rotation invariant
1. DoG scale-space: D(x,y,σ) = G(kσ)⊛I - G(σ)⊛I 2. Locate extrema in (x,y,σ) space 3. Orientation: dominant gradient histogram (36 bins) 4. 128-D descriptor: 4×4 patches × 8-bin histograms
DoG approximates LoG efficiently. Invariant to scale (keypoint size), rotation (orientation assigned), and partially to illumination (normalized descriptor).
sift = cv2.SIFT_create() kp, des = sift.detectAndCompute(gray, None) # des shape: (N, 128) — float32 descriptors
⬢
ORB — Fast & Free
binary descriptor
1. FAST keypoints (pixel ring test) 2. Harris score to top-N 3. BRIEF: sample pixel pairs → binary string 4. Steer BRIEF by keypoint orientation Match: Hamming distance (XOR + popcount)
~100× faster than SIFT. 256-bit binary descriptor → Hamming distance matching. Used in real-time SLAM. FAST tests a circle of 16 pixels for corner speed.
orb = cv2.ORB_create(nfeatures=500) kp, des = orb.detectAndCompute(img, None) bf = cv2.BFMatcher(cv2.NORM_HAMMING)

CDF remapping
CLAHE clip 2
s = T(r) = (L-1) · CDF(r) CDF(r) = Σ p(k) for k ≤ r CLAHE clips histogram at limit before CDF

Contours & Image Moments
Contour finding traces boundaries. Moments provide compact numerical descriptors of shape — area, centroid, orientation.
⬭
Image Moments
shape descriptor
M_pq = Σ Σ x^p · y^q · I(x,y) x y Area = M00 cX = M10/M00 cY = M01/M00 Orientation: arctan(2μ11 / (μ20-μ02)) / 2 M = cv2.moments(contour)
Hu moments (7 values) are invariant to translation, scale, and rotation — used for shape matching. Central moments μ are translation-invariant. cv2.HuMoments(M) returns the 7 Hu descriptors.
⬡
Contour Algorithms
topology
Suzuki-Abe algorithm (1985): Traces borders, encodes topology in hierarchy [parent, child, next, prev] cv2.findContours(binary, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)
CHAIN_APPROX_SIMPLE compresses horizontal/vertical/diagonal runs, storing only endpoints. approxPolyDP uses Ramer-Douglas-Peucker algorithm to simplify curves with ε tolerance.
cnts, hier = cv2.findContours(thresh, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE) area = cv2.contourArea(cnt) perim = cv2.arcLength(cnt, True)
Optical Flow
Estimating apparent motion of pixels between frames. Fundamental for video analysis, tracking, and SLAM.
→
Lucas-Kanade (Sparse)
local method
Brightness constancy: I(x,y,t) = I(x+dx,y+dy,t+dt) ∂I/∂x·u + ∂I/∂y·v = -∂I/∂t → overdetermined Solve with least squares in local window: [u] = (AᵀA)⁻¹ Aᵀ b where A = spatial gradients
Assumes: brightness constancy, small motion, spatial coherence. Aperture problem: only normal flow detectable with 1 equation/pixel. Window provides 2 equations. Fails on large motion → use pyramids.
p1, st, err = cv2.calcOpticalFlowPyrLK( old_gray, frame_gray, p0, None, winSize=(15,15), maxLevel=2)
⇢
Farneback (Dense)
global method
Approximate signal locally as polynomial: I(x) ≈ xᵀ A x + bᵀx + c Motion estimated from polynomial coefficients between frames via weighted least squares. Color-code flow: HSV — angle=Hue, mag=Value
Computes flow for every pixel. More robust than LK but slower. Visualization: convert (dx,dy) to polar → HSV image where hue encodes direction and brightness encodes speed.
flow = cv2.calcOpticalFlowFarneback( prev, next, None, 0.5, 3, 15, 3, 5, 1.2, 0) mag, ang = cv2.cartToPolar(flow[...,0], flow[...,1])
